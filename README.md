# NPA Recovery in Indian Banking: Did IBC 2016 Actually Work?

### A Statistical Analysis of PSU vs Private vs Foreign Banks (2012–2024)



## Objective

Examines whether the Insolvency and Bankruptcy Code (IBC) 2016 had a 

measurably different impact on NPA recovery across Public Sector, 

Private Sector, and Foreign bank groups using RBI data from 2012 to 2024.


**Core questions:**

- Did Gross NPA ratios decline faster post-IBC for PSU banks vs Private banks?
- Which bank group recovered fastest from the 2018–2019 stress peak?
- Was the post-IBC reduction statistically significant?


## Data Sources

- **RBI DBIE** (dbie.rbi.org.in) — Bank-wise Gross NPA, Net NPA, 

&#x20; Gross Advances by bank group 2012–2025

- **RBI Annual Report** — Gross and Net NPA by bank category 2010–2024


Raw files preserved in `/data/raw` without modification.
